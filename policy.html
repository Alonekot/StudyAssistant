Политика конфиденциальности

Дата вступления в силу: 13 июля 2026 г.

Настоящая политика конфиденциальности распространяется на приложение UploudPin для устройств с Windows, разработанное компанией StelTech (далее — «Приложение»). StelTech именуется «Поставщиком услуг».

1. Сбор и использование информации

Приложение не собирает, не хранит и не передаёт какие-либо персональные данные пользователей на серверы Поставщика услуг. Вся информация (включая токен доступа к Pinterest, выбранные изображения, настройки и логи) сохраняется исключительно на локальном устройстве пользователя. Приложение использует API Pinterest исключительно для выполнения операций, инициированных пользователем (загрузка изображений на выбранную доску). Обмен данными с Pinterest осуществляется по защищённому протоколу HTTPS.

Поставщик услуг не имеет доступа к вашим файлам, токенам или любой другой информации, обрабатываемой Приложением. Никакие сторонние аналитические инструменты, рекламные сети или трекеры в Приложении не используются.

2. Ваши права

Поскольку мы не храним ваши данные на своих серверах, удаление Приложения с вашего устройства полностью прекращает обработку любых данных. Если у вас есть вопросы или вы хотите получить дополнительную информацию, вы можете связаться с нами по адресу, указанному в разделе «Контакты».

3. Права жителей Калифорнии (CCPA/CPRA)

Если вы являетесь резидентом Калифорнии, вы имеете право знать, какие персональные данные собираются, право на их удаление и право не подвергаться дискриминации за реализацию этих прав. Поскольку Приложение не собирает данные на наших серверах, эти права автоматически соблюдаются. Для любых уточнений вы можете связаться с нами по электронной почте.

4. Передача данных третьим лицам

Приложение не передаёт ваши данные третьим лицам, за исключением запросов к API Pinterest, которые вы сами инициируете. Эти запросы направляются напрямую к серверам Pinterest и регулируются политикой конфиденциальности Pinterest.

5. Международная передача данных

Поскольку Приложение взаимодействует с API Pinterest, данные (изображения, заголовки, описания) могут передаваться на серверы Pinterest, расположенные в США и других странах. Такая передача осуществляется только по вашему прямому запросу и регулируется условиями использования Pinterest. Поставщик услуг не контролирует и не обрабатывает эти данные на своей стороне.

6. Право на отказ

Вы можете в любой момент прекратить использование Приложения и удалить его с вашего устройства. Это остановит любую обработку данных. Для удаления уже загруженных пинов обратитесь к своему аккаунту Pinterest.

7. Сроки хранения данных

Поскольку данные не хранятся на серверах Поставщика услуг, сроки хранения определяются только вами — вы можете удалить Приложение и все связанные с ним локальные файлы в любое время.

8. Дети

Приложение не предназначено для детей младше 16 лет. Поставщик услуг не собирает данные детей, поскольку никаких данных не собирается в принципе.

9. Безопасность

Приложение использует стандартные механизмы безопасности операционной системы Windows для защиты локально хранимой информации. Все сетевые соединения с Pinterest осуществляются по защищённому протоколу HTTPS.

10. Уведомление об утечке данных

Поскольку Поставщик услуг не хранит ваши данные, утечка данных на нашей стороне невозможна. В случае компрометации вашего аккаунта Pinterest следуйте рекомендациям Pinterest по безопасности.

11. Изменения в политике

Мы можем время от времени обновлять эту политику, чтобы отражать изменения в Приложении или законодательстве. О всех существенных изменениях мы уведомим через обновление документа на этой странице.

12. Ваше согласие

Используя Приложение, вы соглашаетесь с условиями данной политики. Если вы не согласны, пожалуйста, не используйте Приложение.

13. Контакты

Если у вас есть вопросы по этой политике, пожалуйста, свяжитесь с нами по электронной почте: theworldthroughthelens24@gmail.com.
